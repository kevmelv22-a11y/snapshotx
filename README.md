# SnapShot X

This folder contains the separate Expo SDK 57 TypeScript project. The existing Expo Snack uses the adjacent `SnapShot X App.js` with SDK 55.

The SDK 55 `App.js` now has eight photo color looks plus Original. They are composited into saved, shared, and sent photos; video is unchanged. The SDK 57 camera route also waits for video mode before recording and cancels when the shutter is released during setup.

## Run locally

1. Install Node.js 22.13+ for Expo SDK 57 and run `npm ci` in this folder.
2. Create `.env` with `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` from your Supabase project. Never use a service role key in the app.
3. Run `npx expo start` and open the app on a physical iOS or Android device to test camera, media permissions, and sharing.

## Chat screen refresh

The SDK 57 chat screen now has an original purple galaxy background, safe-area header, search, unread/nearby/story filters, a clearly labeled local-only AI example, conversation previews, compose flow, and a five-item Map/Chat/Camera/Friends/Videos bottom bar. Existing Supabase threads, friend selection, camera, map, stories, profile, reporting and moderation routes remain available. The Videos tab displays public video stories; Discover and all-story screens are still separate routes. The optional example conversations are deliberately isolated in `lib/chat-list.ts` and never sent to Supabase. The unread badge is derived from message receipts; ordinary incoming messages are marked read in an open chat, while one-time snaps retain their existing server-side claim flow. A real signed-in, two-account device test is still required; static checks alone do not prove navigation, notification delivery or media behavior on an iPhone.

Follow-up fixes: closing search clears its query; the AI filter displays an explicit local demo row instead of leaving an empty list; the unread indicator checks all fetched incoming messages rather than only the latest message in a thread; the Map tab applies the iPhone top safe area; and returning from a conversation refreshes the tab badge. Ordinary messages are marked read only while their chat screen is focused; navigating away no longer marks background arrivals as read. The list currently inspects the newest 500 messages across the user's threads, so very busy accounts need a server-side unread counter before treating this as an exact historical total.

The camera shortcut on a real conversation now carries its thread to the camera and compose screen. The send action confirms the destination and offers a one-time or 24-hour snap; group chats use their existing thread rather than opening a separate direct chat. Before uploading, the app checks current thread membership; the existing database insert policy also enforces membership and blocks. This path passes TypeScript, lint, Expo Doctor (21/21), and iOS JS export, but has not been exercised on a physical device. The shortcut on explicitly labeled local demo rows opens the general camera without a real destination.
